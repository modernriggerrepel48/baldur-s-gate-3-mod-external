## ✨ Features

The Script Extender expands Baldur's Gate 3's scripting environment with additional functionality, including:

- 🧩 Lua scripting support
- 📜 Osiris scripting extensions
- 🛠️ Developer and debugging tools
- 🐞 Lua and Osiris debugger interfaces
- 📝 Extended logging capabilities
- 🏆 Achievement support for modded games
- 💥 Crash report collection
- 🔧 Additional development utilities
